You'll need Go 1.25 or newer on PATH and a browser. No administrator account is needed for the per-user installer.

01 / GET THE APP

Choose your computer

Download the Linux x64 archive and checksum into the same folder. Verify the checksum before installing.

Download for Linux x64SHA-256 file
RUN IN YOUR TERMINAL
sha256sum -c gobook-v0.8.1-linux-amd64.tar.gz.sha256
tar -xzf gobook-v0.8.1-linux-amd64.tar.gz
cd gobook-v0.8.1-linux-amd64
./install.sh

Not sure about your processor? Linux: uname -m (x86_64 means x64; aarch64 means ARM64). Windows: Settings → System → About → System type.

02 / OPEN YOUR WORKSPACE

Launch GoBook Local

Open GoBook Local from your Linux application menu or Windows Start menu. It starts the local host and opens the authenticated workspace for you.

Prefer the terminal? With Go installed, use:

go run github.com/Alifarid0011/gobook@v0.8.1

The first run downloads and builds Go modules. Open the private URL printed in your terminal. Keep the terminal running.

Good to know
before you run.

Where does my code run?

GoBook runs code on the computer hosting the local app, with your user permissions. Its workers are not security sandboxes. Inspect notebooks before running them. Keep the local capability URL private; it authorizes code execution. GitHub Pages serves this guide, not the app's compiler or kernel.

Which engine should I choose?

Interactive uses Yaegi and retains variables between edits, with bundled standard-library imports and interpreter language limitations. Native uses your Go compiler for versioned modules; source edits need a restart. Use Native for the Penguins notebook. Read the engine guide.

What if GoBook won't start?

Run go version in a terminal first. If Go is missing, install it and restart your terminal. For desktop setup, install again after changing your Go installation. If the default port is occupied, use the desktop troubleshooting guide. Do not post private capability URLs or host logs publicly.

How do I save and close safely?

Download your notebook before closing the page. Export experiment results if you need the outputs too. The app does not provide automatic backups. Closing the browser leaves the desktop host running; use Quit GoBook to stop the host and kernels. Quitting discards live memory.

What platforms are supported?

Release archives cover Linux and Windows, x64 and ARM64. Go 1.25+ is required on every host. macOS can use the source-based Go command, but macOS runtime behavior has not been verified locally. Mobile browsers do not include a Go compiler; running remotely needs a separately managed host.
